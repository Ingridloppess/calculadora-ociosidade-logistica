# calculadora-ociosidade-logistica
A Calculadora de Ociosidade Logística tem como objetivo ajudar empresas a mensurar o impacto financeiro causado por veículos parados.  Muitas empresas conhecem seus custos operacionais, mas não conseguem transformar horas de inatividade em valores monetários. Este projeto busca resolver esse problema através de uma calculadora simples e intuitiva.
